# キーマップガイド（USB キーボード → PB-1000 キー割り当て）

このガイドでは、エミュレータが標準で用意している **USB キーボード → PB-1000 実機キー** の
割り当て（デフォルトキーマップ）を一覧化します。実装は `mp/keymap.py`（フォールバック用の
組み込みデフォルト）および `mp/keymap.json`（同内容を SD カード等から上書きするための
JSON 表現）にあります。

エミュレータ全体の操作（Save State・スクリーンショット・エミュレータメニューなど、
PB-1000 実機に存在しないシステム機能キー）については `usage_guide.md` §3 を参照してください。
本ガイドは **PB-1000 実機のキーに対応する割り当てのみ** を扱います。

---

## 1. しくみ

1. USB キーボードから HID スキャンコード（`0x04`〜など）と修飾キー状態（Shift/Alt/Ctrl/Win）を受け取る。
2. 修飾キーが押されている場合、まず `ADV_MAP`（スキャンコード, mod）の組み合わせで追加マッピングを検索する。
3. 見つからなければ `USB_MAP`（スキャンコードのみ）で直接マッピングを検索する。
4. マッピング結果は PB-1000 キーボードマトリクスの **(row, ki)** 座標（13 行 × 12 列）1 個、
   または複数座標のリスト（例: Shift+別キーの同時押下）として得られ、CPU 側のキースキャンに反映される。

`mod` のビット意味（`get_label()` のコメントより）:

| ビット値 | 修飾キー |
| :--- | :--- |
| 1 | Shift |
| 2 | Alt |
| 4 | Ctrl |
| 8 | Win（GUI） |

### キーマップのカスタマイズ

起動時に以下の優先順で JSON ファイルを探し、見つかればそちらを使用します（見つからなければ
`mp/keymap.py` の組み込みデフォルトを使用）。

```
/sd/roms/keymap.json > /sd/keymap.json > /roms/keymap.json > /keymap.json
```

## 2. 直接マッピング（USB_MAP）

修飾キーなしで、USB スキャンコード 1 個から PB-1000 キーへ直接変換されるものです。

### アルファベット・数字

USB キーボードの `A`–`Z` / `0`–`9` は、そのまま PB-1000 の同じ文字キーに割り当てられます
（スキャンコード `0x04`–`0x1D` が `A`–`Z`、`0x1E`–`0x27` が `1`–`0`）。

### 記号・その他ベースキー

| USB キー（スキャンコード） | PB-1000 キー |
| :--- | :--- |
| Space（`0x2C`） | SPACE |
| `-`（`0x2D`） | `-` |
| `=` 位置＝JIS `^`（`0x2E`） | `^` |
| `;`（`0x33`） | `;` |
| `'` 位置＝JIS `:`（`0x34`） | `:` |
| `,`（`0x36`） | `,` |
| `.`（`0x37`） | `.` |
| `/`（`0x38`） | `/` |
| Grave 位置＝JIS カナ切替（`0x35`） | KANA |
| CapsLock（`0x39`） | CAPS |
| International4／JIS 変換キー（`0x8A`） | ENG |

> JIS キーボードの物理キー位置を前提にした割り当てが含まれます（`0x2E`＝`^`、`0x34`＝`:` など）。
> US 配列キーボードでは印字と一致しない場合があります。

### 編集・カーソル

| USB キー | PB-1000 キー |
| :--- | :--- |
| Enter（`0x28`） | EXE |
| Esc（`0x29`） | BREAK |
| Backspace（`0x2A`） | BS |
| Insert（`0x49`） | INS |
| ↑ / ↓ / ← / →（`0x52`/`0x51`/`0x50`/`0x4F`） | カーソル上下左右（長押しでリピート） |
| Pause（`0x48`） | CLS |
| End（`0x4D`） | STOP |

### ファンクションキー（PB-1000 固有キー割り当て）

| USB キー | PB-1000 キー |
| :--- | :--- |
| F1（`0x3A`） | F1（タッチキー TK13 相当） |
| F2（`0x3B`） | F2（TK14 相当） |
| F3（`0x3C`） | F3（TK15 相当） |
| F4（`0x3D`） | F4（TK16 相当） |
| F5（`0x3E`） | LC KEY |
| F6（`0x3F`） | MENU |
| F7（`0x40`） | CAL |
| F8（`0x41`） | MEMO IN |
| F9（`0x42`） | MEMO |
| F10（`0x43`） | IN |
| F11（`0x44`） | OUT |
| F12（`0x45`） | CALC（Win＋F12 の場合は後述の NEW ALL） |

### その他

| USB キー | PB-1000 キー |
| :--- | :--- |
| Application／メニューキー（`0x65`） | ANS |
| International3／JIS ¥ キー（`0x89`） | ENG（※単独時。Shift 併用時は下表参照） |

## 3. 修飾キー単体のマッピング

左右どちらの Alt / Ctrl キーも、それ自体を押しただけで PB-1000 の該当キーとして扱われます。

| USB キー | PB-1000 キー |
| :--- | :--- |
| Alt（左）／Alt（右） | SHIFT |
| Ctrl（左）／Ctrl（右） | Func |

---

## 4. Shift との組み合わせ（記号入力・ADV_MAP）

USB キーボードで `Shift+◯◯` を押したとき、PB-1000 側では別のキー（または PB-1000 の
SHIFT キー＋別キーの同時押下）に変換され、PC の記号入力感覚に近い文字が得られます。

| USB キー（Shift＋） | PB-1000 側の入力 | 得られる文字 |
| :--- | :--- | :--- |
| `1`（`0x1E`） | SHIFT + `"`キー | `!` |
| `2`（`0x1F`） | `"`キー | `"` |
| `3`（`0x20`） | SHIFT + `$`キー | `#` |
| `4`（`0x21`） | `$`キー | `$` |
| `5`（`0x22`） | SHIFT + `&`キー | `%` |
| `6`（`0x23`） | `&`キー | `&` |
| `7`（`0x24`） | SHIFT + `=`キー | `'` |
| `8`（`0x25`） | `[`相当キー | `(` |
| `9`（`0x26`） | `]`相当キー | `)` |
| `-`（`0x2D`） | `=`キー | `=` |
| `;`（`0x33`） | `+`キー | `+` |
| `'`（`0x34`） | `*`キー | `*` |
| `/`（`0x38`） | SHIFT + `,`キー | `?` |
| `,`（`0x36`） | SHIFT + `;`キー | `<` |
| `.`（`0x37`） | SHIFT + `:`キー | `>` |
| Esc（`0x29`） | CLS キー | CLS |
| `]`（`0x30`） | SHIFT + `*`キー | `{` |
| Non-US #（`0x32`） | SHIFT + `/`キー | `}` |
| International1（`0x87`） | SHIFT + `8`キー | `_` |
| `[`（`0x2F`） | SHIFT + `9`キー | `` ` `` |
| International3／¥（`0x89`） | SHIFT + `4`キー | `\|` |
| `=`／JIS `^`（`0x2E`） | SHIFT + `5`キー | `~` |

## 5. 特定キー単独の追加割り当て（ADV_MAP・修飾キーなし扱い）

以下は USB_MAP に無いスキャンコードを、ADV_MAP 側で個別に定義しているものです
（Shift を押していなくても、そのキー固有の変換として適用されます）。

| USB キー | PB-1000 側の入力 | 得られる文字／機能 |
| :--- | :--- | :--- |
| Delete（`0x4C`） | SHIFT + INS | DEL |
| Home（`0x4A`） | SHIFT + CLS | HOME |
| `[`（`0x2F`） | SHIFT + `7`キー | `@` |
| `]`（`0x30`） | SHIFT + `[`相当キー | `[` |
| Non-US #（`0x32`） | SHIFT + `]`相当キー | `]` |
| International1（`0x87`） | SHIFT + `6`キー | `\`（バックスラッシュ相当） |
| International3／¥（`0x89`） | SHIFT + `^`キー | `¥`（円記号） |
| ScrollLock（`0x47`） | CONTR. キー | CONTR. |

## 6. NEW ALL キー

PB-1000 の **NEW ALL** キー（全消去）は、単独の USB キーには割り当てられておらず、
**Win（GUI）＋ F12** の組み合わせに割り当てられています。

| USB キー | PB-1000 マトリクス座標 | PB-1000 キー |
| :--- | :--- | :--- |
| Win（GUI）＋ F12（`0x45`, mod=8） | (row 6, ki 6) | NEW ALL |

Win 修飾なしで F12（`0x45`）単体を押した場合は、通常どおり **CALC** キーとして扱われます
（§2 参照）。

---

## 7. タッチキー（TK1–TK16）との対応

`mp/keymap.py` の `KEY_MAP` には、USB キーとは独立に PB-1000 の 16 キータッチパネル
（TK1–TK16）とマトリクス座標の対応も定義されています。

| タッチキー | 座標 (row, ki) | タッチキー | 座標 (row, ki) |
| :--- | :--- | :--- | :--- |
| TK1 | (7, 12) | TK9  | (7, 10) |
| TK2 | (8, 12) | TK10 | (8, 10) |
| TK3 | (9, 12) | TK11 | (9, 10) |
| TK4 | (10, 12) | TK12 | (10, 10) |
| TK5 | (7, 11) | TK13 | (7, 9) |
| TK6 | (8, 11) | TK14 | (8, 9) |
| TK7 | (9, 11) | TK15 | (9, 9) |
| TK8 | (10, 11) | TK16 | (10, 9) |

TK13–TK16 は §2 の F1–F4 と同じ座標であり、USB キーボードの F1–F4 とタッチパネルの
TK13–TK16 は事実上同じ PB-1000 キーを指しています。
