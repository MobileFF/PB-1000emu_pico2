# EMULATOR MENU 利用ガイド

PB-1000 エミュレータには、実機の PB-1000 には存在しない「エミュレータ自体の設定・機能」を
まとめた **EMULATOR MENU** が用意されています。この文書では、その開き方・操作方法・
各項目の内容を説明します。

> 本ガイドは利用者向けです。内部実装の詳細（ソースコードの構造など）については
> `dev_guide.md` を参照してください。

---

## 1. 開き方・閉じ方

| キー操作 | 動作 |
| :--- | :--- |
| **Win（GUI）+ F7** | EMULATOR MENU を開く |
| **↑ / ↓** | カーソル移動（このメニュー内でのみ有効） |
| **EXE** | カーソル位置の項目を選択・実行 |
| **BREAK** | 1つ前の画面に戻る（サブメニュー内）／メニューを閉じる（最上位画面） |

メニューを開いている間は PB-1000 本体の動作（CPU の実行）は一時停止します。
メニューを閉じると、その時点まで実行されていたプログラムの続きから動作が再開します。
設定変更はメニュー内で即座に反映され、`pb1000.ini` への保存が明記されていない項目は
再起動すると元に戻ります。

---

## 2. メニュー構成

EMULATOR MENU は次の4つのカテゴリと **Exit** で構成されています。カテゴリを選ぶと
そのカテゴリ専用のサブメニューが開きます。

```
== EMULATOR MENU ==
├─ Toggles   （各種機能のON/OFF切り替え）
├─ Storage   （ディスク・RAM・画面のセーブ/ロード）
├─ Display   （表示色・解像度・HDMI出力の設定）
├─ System    （システム情報・リセット関連）
└─ Exit      （メニューを閉じる）
```

各項目の右端には現在の状態を示す **バッジ**（`ON` / `OFF` / `N/A` や設定値）が表示されます。

---

## 3. Toggles（各種機能のON/OFF）

| 項目 | 内容 |
| :--- | :--- |
| **Serial Console** | LCD に表示されている文字をコンソール UART（GP4/GP5）へリアルタイム出力する機能の ON/OFF |
| **RS-232C (PIO)** | PB-1000 の RS-232C インターフェース（仮想シリアル通信）の ON/OFF |
| **vFDD** | 仮想フロッピードライブの ON/OFF。**FDD が通信中は OFF にできません**（メッセージが表示されます） |
| **Beep** | ビープ音のミュート切り替え |
| **Joystick** | ジョイスティック入力の ON/OFF |
| **Color VRAM (VDP)** | 画面をモノクロ2色ではなく、ピクセル単位のカラー表示に切り替える機能の ON/OFF |

これらはすべて EXE でその場で ON ⇔ OFF が切り替わります（設定ファイルへの保存はしません）。

---

## 4. Storage（保存・読み込み）

| 項目 | 内容 |
| :--- | :--- |
| **FD Swap** | 仮想フロッピーディスクのディスクイメージを切り替える |
| **RAM Save** | 現在の RAM の内容と CPU の状態（PC・レジスタ）を SD カード（`/sd/rams/`）にスナップショットとして保存する |
| **RAM Load** | 保存済みのスナップショットから RAM と CPU の状態を復元し、保存した瞬間の続きから実行を再開する |
| **VRAM Save** | 現在の画面内容（LCD VRAM）をファイルとして保存する（PrintScreen キーと同じ機能） |
| **Full Capture** | ベゼルやファンクションキーバーを含む画面全体を1枚の画像（PPM）として保存する |

> [!WARNING]
> **RAM Load を実行すると、その場で現在の RAM とプログラムの実行状態が上書きされ、
> EMULATOR MENU は自動的に閉じます。** リセット（PC=0x0000 に戻す）は行われず、
> RAM Save を実行した時点の PC・レジスタからそのまま続きが再開します。
> 実行中のプログラムの内容は破棄されるので、必要であれば先に RAM Save で保存してください。

**RAM Save** と **RAM Load** はいずれも、選択時に保存先／読み込み元のフォルダ名を選ぶ画面が
開きます（新規保存の場合は英数字とハイフンでフォルダ名を入力できます）。

---

## 5. Display（表示関連）

| 項目 | 内容 |
| :--- | :--- |
| **Foreground Color** | LCD の「点灯」ピクセルの色を変更する |
| **Background Color** | LCD の「消灯」ピクセルの色を変更する |
| **LCD Height** | LCD の縦解像度を 32 ドット / 64 ドットで切り替える |
| **HDMI** | 第2 Pico 2 ＋ HDMI出力アドオンへのミラー出力の ON/OFF（[hardware_guide.md](hardware_guide.md) §9） |

**Foreground Color** / **Background Color** を選択すると、色の数値（RGB332形式、0〜255）を
入力する画面 → 実際の色見本を確認する画面、の順に進みます。EXE で確定すると `pb1000.ini` に
保存され、次回起動時にも同じ色になります。

**LCD Height** は EXE を押すたびにその場で 32 ドット ⇔ 64 ドットが切り替わります（サブ画面は
ありません）。他のトグル系項目と同様に `pb1000.ini` への保存はされないセッション限定の設定で、
再起動すると `[display] lcd_height` の設定値に戻ります。64 ドットへ切り替えた直後は、追加された
行（5〜8 行目）にプログラムがまだ描画していない古い VRAM の内容が残ることがありますが、これは
実機の PB-1000 でも同様の挙動であり不具合ではありません。

**HDMI** は EXE を押すたびにその場で ON ⇔ OFF が切り替わり、`pb1000.ini` の `[hdmi] enable` にも
即座に保存されます（他の Toggles 系項目と異なり、こちらは再起動後も設定が保持されます）。
**ON にすると物理 LCD への描画が止まり、画面は EMULATOR MENU 自体を含めてすべて HDMI 側に
表示されるようになります**（LCD と HDMI は排他出力。詳細は
[usage_guide.md](usage_guide.md) §11）。HDMI出力アドオンを配線していない状態で ON にしても
実機の動作に害はありませんが、画面が LCD にもHDMIにも表示されなくなる（何も繋がっていない
SPI へ送信するだけになる）ため、確認用のアドオンを配線してから ON にしてください。

## 6. System（システム関連）

| 項目 | 内容 |
| :--- | :--- |
| **Hook Status** | 現在有効になっている拡張機能（`mp/ext/` 配下のモジュール等）の一覧を表示する、読み取り専用の確認画面 |
| **CPU Status** | 現在の CPU レジスタ（PC・フラグ・UA・IA/IB/IE・IX〜KY・$0〜$31）と PC 周辺の生バイト列・逆アセンブルを表示する、読み取り専用の確認画面 |
| **Reset** | PB-1000 実機の NumLock キーと同じ、**エミュレートされた PB-1000 のリセット**をその場で実行する（Pico 自体は再起動しない） |
| **Reboot Emulator (MCU)** | **Pico 本体そのもの**を `machine.reset()` でハードウェアリブートする（下記警告参照） |
| **NEW ALL (clear memory)** | PB-1000 の NEW ALL 機能（ユーザーメモリの全消去）を実行する |

> [!WARNING]
> **NEW ALL はユーザーの全メモリ（保存されているプログラムやデータ）を消去します。**
> 実行前に確認画面（EXE:yes / BRK:no）が表示されるので、誤って実行しないよう注意してください。
> この操作は元に戻せません。

> [!WARNING]
> **Reboot Emulator (MCU) は Reset とは別物で、Pico 本体を実際に再起動します。** 実行前に
> 確認画面が表示されますが、**RAM Save していない進行状況は失われます**（プロファイル選択画面
> から起動シーケンス全体がやり直しになるため）。必要であれば実行前に **RAM Save** で
> バックアップしてください。フリーズ・ハングしてしまい実行状態からの復帰が困難な場合の
> 手段として用意されています。

**Reset** は確認画面なしでその場で即座に実行され、EMULATOR MENU も自動的に閉じます
（実機の NumLock キーを押したのと同じ動作です）。**Reboot Emulator (MCU)** はこれとは異なり、
確認画面（EXE:yes / BRK:no）を経てから実行されます。

**Hook Status** / **CPU Status** の各画面内では ↑↓ キーで一覧をスクロールでき、BREAK で
System サブメニューに戻ります。

---

## 7. 困ったときは

- **メニューの階層を間違えて戻れなくなった** → BREAK を繰り返し押せば、サブメニュー →
  最上位メニュー → メニューを閉じる、の順に必ず戻れます。
- **間違えて Color VRAM を切り替えてしまった** → もう一度同じ項目を EXE すれば元に戻ります。
- **RAM Load や NEW ALL を実行してしまった** → これらはその場で反映される操作のため、
  取り消しはできません。日頃から **RAM Save** でこまめにバックアップを取ることをお勧めします。
